# Daily Brew

A simple café website for the Bootstrap midterm. Open `index.html` in a browser to run it. No installation or internet connection is needed.

## Files

- `index.html` — page content with short section comments.
- `style.css` — a few custom colors and image styles.
- `assets/images/` — three original SVG illustrations.
- `assets/vendor/` — Bootstrap 5.3.3 CSS and bundled JavaScript (MIT license; license links are in their file headers).

## Assignment requirements

- Two-column hero: `col-lg-6`.
- Three-column menu: `col-lg-4`, with `col-md-6` and `col-sm-12` for smaller screens.
- Bootstrap containers and spacing utilities, including responsive spacing.
- Responsive navbar with a hamburger button and four links.
- Bootstrap solid, outline, large, and small buttons.
- Three-image carousel with indicators and previous/next buttons.
- Three image cards inside a responsive `card-group` grid.
- Semantic HTML, descriptive image text, labeled controls, and a skip link.

The optional form and button group are omitted to keep the project simple. The carousel changes manually, so there is no distracting automatic movement. Bootstrap supplies all interaction; no custom JavaScript is needed.

The café, prices, and opening hours are demonstration content. Edit the text in `index.html` to personalize it.
